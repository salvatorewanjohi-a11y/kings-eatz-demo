# Perfect Bite by Kings Eatz: smoked sausage shop demo

A demo of the Perfect Bite (Kings Eatz) WooCommerce shop for Elvis Kahwai's small-batch smoked sausages, Nairobi, running entirely in the browser with WordPress Playground.

- Shop: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/kings-eatz-demo/main/blueprint.json
- Store admin (packs, batch stock, orders, party requests): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/kings-eatz-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so test orders are not kept.
